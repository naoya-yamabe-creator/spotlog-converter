# spotlog ➔ 基準様式 Excel自動変換ツール

spotlog形式の療養費支給申請書（Excel）を、厚生労働省の基準様式フォーマット（はり・きゅう様式第5号の1、マッサージ様式第5号の2）へ高精度かつ一括で自動変換するWebアプリケーションです。

---

## 🌟 主な特徴

- **複数ファイル・複数シート一括変換**: ドロップゾーンに置くだけで、全患者のデータを1つの基準様式ブックに統合出力。
- **高精度レイアウト完全再現**: 結合セル・列幅・行高・罫線・フォント・カレンダー摘要印字の細部まで崩さず転記。
- **不適合シート自動スキップ**: 逓減算定や非対応シートを自動検知して安全にスキップ。
- **端末自動ダウンロード**: 変換完了時にブラウザ経由でお手元のPCへ自動ダウンロード。

---

## 🚀 ローカルでの起動方法

```bash
# 依存ライブラリのインストール
pip install -r requirements.txt

# Streamlit アプリ起動
streamlit run app.py
```
